# Shuttle Arena 3D v1.0 — Official MVP

Giải nén vào một thư mục mới để giữ bản gốc của ông.

- Chơi bản tải từ nhánh GitHub: mở **shuttle-arena/index.html**. Gói cục bộ có thêm **Shuttle_Arena_3D_v1.0_OFFICIAL_MVP.html**; có thể tạo lại bằng script trong `shuttle-arena/tools/`.
- Đọc báo cáo phát hành: **shuttle-arena/OFFICIAL_RELEASE.md**. Báo cáo Bước 4–5 được giữ để truy vết.
- Source đang chạy: **shuttle-arena/src/main.js** (phát triển từ game_v06.js) và **src/rules.js**.
- Cách chạy test/build file đơn: **shuttle-arena/README.md**.
- Gói **Shuttle_Arena_3D_v0.6_Package/** là baseline cũ giữ nguyên để so sánh, không phải điểm chạy bản mới.

ZIP không chứa .git, không thay remote/credentials hoặc lịch sử repository của ông. Source gốc v0.3/v0.6 và các doc vẫn có trong gói. Chưa push/deploy. Mở trực tiếp file có thể phụ thuộc chính sách trình duyệt; static server local được hướng dẫn trong README.
